# Інтерактивна сторінка: Flippity

Односторінковий навчальний ресурс українською мовою на основі презентації про Flippity.

## Що є на сторінці
- коротка теорія про призначення Flippity;
- покроковий алгоритм створення активності на основі шаблону Google Таблиць;
- компетентнісне завдання з контрольним списком і полем для плану;
- тест із 6 запитань, автоматичним підрахунком результату та поясненнями;
- рефлексія.

## Як переглянути локально
Відкрийте `index.html` у браузері.

## Як опублікувати на GitHub Pages
1. Створіть новий репозиторій на GitHub.
2. Завантажте `index.html` і цей `README.md` у корінь репозиторію.
3. Відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** виберіть **Deploy from a branch**.
5. Виберіть гілку `main` і папку `/ (root)`, натисніть **Save**.
6. Після публікації GitHub покаже адресу сайту в розділі Pages.

Сторінка не потребує сервера, фреймворків, API-ключів або сторонніх бібліотек. Відповіді тесту перевіряються у браузері; дані з полів не надсилаються на сервер.
